# See your first items

Connecting GitHub during first run creates these starter feeds:

- **My open PRs**
- **Assigned**
- **Notifications**
- **Review requests**

Select a feed in the sidebar, then select an item to open its details. New items arrive unread. Use the item menu to archive it, open it in a browser, or run an available action.

Sources poll every five minutes by default. Press <kbd>r</kbd> to refresh now. Press <kbd>?</kbd> for the current shortcut list.

## Change the starter workspace

Open the flow editor to add sources, filters, feeds, actions, or notifications. You can also open **Chats**, select the **Hive** workspace, and describe the feed you want.

See [Flows](../inbox/flows.md) for a small example and [Sources](../inbox/sources.md) for supported providers.
