# Turn on notifications

Select **Allow notifications** during first run and approve the operating system prompt.

On macOS, Hive cannot show background banners until this permission is granted. If you skipped or denied it, open **Settings ▸ Notifications**. A denied permission must be changed in macOS System Settings.

The same Settings page controls:

- automatic delivery, which uses banners while Hive is in the background;
- system banners at all times;
- in-app toasts at all times;
- the notification master switch and sound.

You can skip notification permission and continue using feeds.
