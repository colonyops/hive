# mise is the task interface and the Taskfile is wails3 build dispatch

- **Status:** accepted
- **Date:** 2026-08-05

## Context

The repo carries two task runners: mise (`mise.toml` and each program's
`tasks.toml`) and the wails3 Taskfiles (`cmd/desktop/Taskfile.yml`,
`cmd/desktop/build/**/Taskfile.yml`). Which one owned a job was not derivable
from either file.

## Decision

**The Taskfile stays, because wails3 runs it.** `wails3 build` and
`wails3 package` execute the `build` and `package` tasks in
`cmd/desktop/Taskfile.yml`, and `wails3 dev` runs `cmd/desktop/build/config.yml`'s
`dev_mode.executes`. The release path calls tasks directly:
`cmd/tools/release/publish.go` runs `wails3 task darwin:package:universal` and
`cmd/desktop/scripts/build/build-linux-docker.sh` runs `wails3 task linux:build`.
Replacing the Taskfile would mean reimplementing universal binaries, bundle
layout, signing, notarization, and Linux packaging. go-task ships inside the
wails3 binary pinned in `mise.toml`, so there is no extra tool to drop.

**mise is the only interface.** `cmd/desktop/Taskfile.yml` holds only what
wails3 reaches: `build`, `package`, `run`, and `setup:docker` (named in the
platform Taskfiles' precondition messages). `desktop:serve` is a mise task
rather than `common:run:server`, because that path regenerates bindings with
`-tags server` and would fight the committed set `desktop:check:bindings`
verifies.

**Task names are area-first and most-specific-last.** Bare names are repo-wide
generation and gates (`generate`, `test`, `lint`, `check`, `ci`, `check:adr`).
Each program's tasks carry its prefix (`cli:*`, `desktop:*`, `docs:*`), for
example `desktop:frontend:test` and `desktop:build:linux:image`.

## Consequences

- Calling `wails3 task <name>` directly reaches past the interface; only the
  release code and the Linux build script have reason to.
- `cmd/desktop/build/**` stays upstream-shaped and is regenerated by
  `wails3 update build-assets`, so a wails3 upgrade is a regeneration, not a
  merge. The one deliberate deviation is pinned by
  `cmd/desktop/build/taskfile_test.go`.
