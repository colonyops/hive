## Added

- **Review server sessions in Changes.** In Code, read the diff of a server session's checkout and send a review to its agent over SSH. Comments the agent writes with `hive review diff put` appear in Changes, where you can dismiss them. The server needs the same hive version.
- **See who owns a task and what its agent is doing.** Tasks show the assigned session and its live agent status: working, needs approval, ready, or not running. Click a session chip to open that session on the agent's window.
- **Flows can message agents and create tagged tasks.** The **Publish message** node publishes to a hive messaging topic for each new version of an item. **Create task** creates one task per item with the tags you list, which you can find with `hive hc list --tags`. Neither node needs an `actions.yml` entry.
- **Agents can manage tasks, messages, and todos through MCP.** The `hive-desktop` MCP server lets agents claim and update tasks, publish and read messages, and add operator todos with tools such as `task_next`, `message_create`, and `todo_create`.
- **Read file trees, call paths, and forge cards in Drive docs.** Fenced `hive-tree`, `hive-calls`, and `hive-forge` blocks render inline, and `[[wikilinks]]` link documents in the same space.
- **Applets can render fenced blocks in Drive docs.** Add a `markdown` surface to `applet.yaml` and list the fence names. The applet draws each matching block; Settings ▸ Applets turns the surface on or off.

## Fixed

- **Drive comment handles no longer cover list numbers.** Every handle sits in one column to the left of the text.
