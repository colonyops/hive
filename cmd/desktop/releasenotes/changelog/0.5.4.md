## Added

- **Hive CLI configuration in Settings**, with the config path Hive Desktop
  uses, CLI documentation, create and open actions, and clear restart and
  default-agent guidance.

## Changed

- **⌘+ and ⌘- now step the terminal text size** instead of zooming the
  window, so the grid reflows and rewraps rather than growing a horizontal
  scrollbar. They walk the same sizes as Settings ▸ Terminal and the change
  persists; ⌘0 puts it back to medium. On Windows and Linux use Ctrl+Shift
  with the same keys from a terminal. Window zoom is gone from the View menu,
  since it never reflowed anything.

## Fixed

- **A session that fails to start keeps what you typed.** The New Session form
  comes back with the repository, name, prompt and agent you submitted, and
  names the step that failed, git's own reason for failing, and the checkout
  left on disk. The failure raises an error toast with a Retry, and lands in
  Activity with a Retry of its own that still works after a restart.
- **Clearer profile setup in onboarding.** First run explains how profiles
  organize your work, labels and focuses the name field, and skips account
  setup when GitHub is already connected.
