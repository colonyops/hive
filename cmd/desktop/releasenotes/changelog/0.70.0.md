## Added

- **Agent reviews and more context in Changes.**
  - Agents can review a session's branch diff. Their comments appear inline with the agent's mark and on the new Overview page. Press `w` to walk through them, dismiss the ones you disagree with, and send the rest to the session's agent alongside your comments.
  - Click a file in the list to see it on its own; press `f` or use the toolbar to show every file again. Click a hunk separator to reveal unchanged lines.
  - Comment on a whole file from its header or with `c`. Use Send with a note or `C` to add a note on all the changes when you send.
- **Install the matching `hive` command from Desktop.** First run offers to link `~/.local/bin/hive` to the app; Settings ▸ Hive CLI has the same switch, controlled by `hive_cli.install_command` in `settings.yaml`. The command follows app updates, so its version stays matched. Existing CLI installs are not overwritten; Settings shows which command your shell finds and warns when its version differs.

## Changed

- **A separate CLI install is no longer needed for the experimental daemon.** Desktop starts it from its own executable, which also runs the CLI when invoked as `hive`. You no longer need `daemon.hive_path` in `settings.yaml`.
- **Update prompts and skills to the new MCP tool names.** Hive Desktop and Hive Drive tools use noun-first names: `open_tab` becomes `tab_open`, `write_document` becomes `document_put`, `list_inbox` becomes `inbox_list`, and `execute_flow` becomes `flow_preview`. The old names are gone. The caller argument is `caller`, not `session`, and profile ids use `profileId` instead of `profile` or `flowId`. `document_delete`, `canvas_delete`, `profile_delete`, and `schedule_delete` return what they deleted, `deleted: true`, and the time.
- **Agent MCP connections no longer need a fixed port when a matching CLI is installed.** Agent workspaces and Settings ▸ MCP servers ▸ Add use `hive mcp serve` for Hive Desktop and Hive Drive when the `hive` command matches the app version. Without a matching CLI, they keep the HTTP address.
- **Drag reorders preview the final position.** Profiles, actions, and inbox feeds and folders slide into place while you drag, rather than showing an insertion line.
- **Quieter tabs in Code and Chats.** Chats puts workspace buttons in the tab row, leaving one bar above the chat instead of two. Tab names in both views use the interface font.

## Fixed

- **⌘1 through ⌘9 count every Code tab**, including Drive, Diff, and Tasks. With a terminal, Drive, and another terminal open, ⌘2 goes to Drive. The command palette shows the same numbers.
- **Embedded code in Changes has syntax colors.** Vue, Svelte, Astro, HTML, PHP, and Markdown diffs no longer show code inside blocks such as `<script>` or `<style>` as plain text.
- **An older local daemon no longer keeps serving old code after an app update** (experimental). The first session call restarts an older release daemon from Desktop's executable; agents keep running. If a service unit still starts an old binary, Desktop logs a warning: run `hive daemon install` to update the unit.
- **The keyboard stays with your terminal.** Closing a Code tab or letting its shell exit gives focus to the next tab. Switching back to Chats focuses the open chat. Dismissing the command palette without running a command restores focus to what had it, including the terminal you were typing in.
- **The last lines of a diff stay visible** in Changes instead of getting cut off below the scroll area.
- **The scratch terminal's `+` opens a terminal straight away.** Code no longer offers agents in menus where they cannot run.
- **A chat whose agent exits just after startup shows the "exited immediately" notice**, rather than an attach error.
