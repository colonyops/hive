## Added

- **Peer agent windows for a shared checkout.** Start a configured profile, such as Codex or Claude, from the Code session header’s + menu or the command palette. The new agent opens beside your current session and shares its checkout.
- **Feed filtering by author.** Choose an author from the Feed options menu when items include one, combine it with search and unread filtering, and clear it from the author chip above the list.
