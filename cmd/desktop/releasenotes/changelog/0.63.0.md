## Added

- **A redesigned Diagnostics workspace** lets you search recent Hive logs and job outcomes, then start an optional agent investigation beside the evidence. Open it from the Window menu or command palette.
- **Canvas metadata and deletion (experimental).** Agents can add front matter, and you can copy or save it with the document or delete the canvas from its toolbar.

## Fixed

- **Terminal failures keep their explanation.** Code retains copyable startup errors and confirmed termination notices after the terminal closes. Restart starts a new process, and also recovers a session whose launch did not finish; Reconnect restores a lost connection. Successful setup commands leave healthy panes running.
