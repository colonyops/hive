## Added

- **Editable session tags in Code.** Edit session, in the session menu or command palette, replaces Rename and changes a session's name and tags in one dialog. Tagged rows show a tag icon, the status bar lists the attached session's tags, and the sidebar filter matches tags. Launch-session actions and flow launch nodes can set tags, and agents can find and retag sessions with the `list_sessions` and `edit_session_tags` MCP tools. New sessions launched from inbox items no longer get the item ID as a tag; existing tags stay.
- **Recent documents in Drive.** The sidebar's collapsible Recent section lists the newest documents across every space, so a document an agent just wrote is one click away.
- **Pin new chats to Code (experimental).** Choose Pin to Code in the New chat dialog to put the new chat in the Code sidebar without pinning it afterward.

## Changed

- **Tasks has a List/Board switch.** Choose Board to drag tasks between status columns. The detail pane lists an epic's sub-tasks, and the repository picker is searchable.
- **Drive reviews are off by default**, including for documents with existing comments. Use the comment button in a Markdown document's header on the Drive page to show comments and enable reviews. Hive remembers the choice across documents; turning reviews off does not delete comments.
- **Start and Stop match the session state in Code.** The session menu offers Start session for stopped sessions and Stop session for running ones. Use Stop session in the menu or command palette where you previously used Kill terminal.
