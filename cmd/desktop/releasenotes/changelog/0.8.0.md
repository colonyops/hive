## Added

- **Pinned feeds in the menu bar.** Pin up to three feeds in Settings ▸ Menu bar to list their newest items in the menu bar dropdown. Each item opens in the browser or in Hive, copies its link, or runs any configured action that needs no further input. A Profiles submenu opens a profile in Hive. The menu no longer turns profiles on and off; do that from the profile's settings.

## Changed

- **⌘+ and ⌘- keep growing the terminal text** instead of stopping at the largest preset. The size is a pixel count now, stepped 2px a press between 8px and 64px, and Settings ▸ Terminal offers a stepper in place of the five named sizes. `terminal_font_size` in `settings.yaml` is now a number of pixels, and the app converts a saved name such as `large` to its size on first launch.

## Fixed

- **Feed search finds items by number.** Search for a pull request or issue with `278` or `#278`.
- **Terminal trackpad scrolling reaches mouse-aware programs.** Scroll Neovim and other full-screen programs without moving the terminal scrollback instead. (experimental)
- **The Code tab's session tree no longer brings back a closed shell.** A shell closed in one session stays gone after you switch between other sessions.
