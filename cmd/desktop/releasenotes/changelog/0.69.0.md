## Added

- **Tabs and splits in Code.** A session's windows show as tabs above the terminal, and the `+` on a tab row adds a terminal, an agent, or a Drive, Diff, or Tasks tab. Split a panel right or down, nest splits, drag tabs between panels, resize with a divider, and turn a split between side by side and stacked. A dragged tab follows the pointer, and the target panel marks where it will land. The sidebar lists every tab in the same order, and Hive remembers each session's layout across restarts.
- **Review changes in a Diff tab.** Read a local session's diffs in one scroll beside its file list. Compare branch changes, uncommitted work, staged or unstaged work, or one commit at a time. Search the diffs, comment on selected lines or code, and send the comments to the session's agent. Open Diff from the session's `+` menu or the line counts in the status bar. Diff review is not available for sessions on servers.
- **Sessions on servers in Code** (experimental). Code lists sessions from each server under `servers:` in the hive config next to your local sessions. Create, open, edit, recycle, and delete a server session, or choose Start when its terminal has stopped; its terminal runs over ssh using the server's rules. Its status bar shows the server name, branch, uncommitted changes, and pull request. Open in editor, Show in Finder, and configured actions stay hidden because they act on this machine. Settings ▸ Servers shows each server's last check. An offline server sends a notification and shows a red status dot with its ssh error on hover, without slowing down the local list.
- **Applets** (experimental). Ask an agent for a custom web page with full access to your machine; Applet Builder asks for a style and writes the prompt. Open an applet from the command palette or a shortcut, in a session tab from the `+` menu in Code or Chats, or in the title bar with a dropdown. `applet.yaml` lists its surfaces and commands; a running page can also add palette rows and run Hive commands. Shortcuts work while the page has focus, and agents can open and close applet tabs. Settings ▸ Applets shows registered and running applets, lets you turn one off or delete it, and exports or imports `.hiveapplet` files. Import only applets you trust: import warns you, shows the files and what would run, and never replaces an existing applet.
- **Images in Drive.** Select an image in the Drive tree to open it in the reader.
- **Task actions in list rows.** Click a task's status icon to set its status, hover for Mark done or Reopen and a menu with Copy ID and Delete, or right-click for the same menu. Press `d` to mark the selected task done or reopen a closed task.

## Changed

- **Text size is a percentage for each area.** Settings ▸ Appearance ▸ Text size sets Interface, Documents, Code, and Terminal separately. ⌘+, ⌘-, and ⌘0 change the area you last clicked or focused. Your terminal and document sizes carry over. In `settings.yaml`, `terminal_font_size` and `canvas_font_size` become `terminal_scale` and `document_scale`; their `HIVE_DESKTOP_APPEARANCE_*` overrides use the new names too.
- **Drive is a tab in Chats too.** The separate Drive pane is gone. Use `+` on a chat's tab row to open Drive, then split the panel to read beside the conversation. A document an agent opens arrives as a background Drive tab with a dot until you read it; `hive://chats` links with `canvas=` open that tab too. The title bar's right button no longer toggles Drive in Code or Chats.
- **Agents can arrange tabs and panels.** The Hive Drive MCP tools `open_tab`, `close_tab`, `move_tab`, `focus_tab`, `close_panel`, `resize_split`, `turn_split`, and `get_layout` replace `open_document`, `open_canvas`, and `close_canvas`. `open_tab` opens Drive, Diff, Tasks, a terminal, or an applet behind the current tab, beside it, or below it. A new terminal is a shell in the Code session's checkout, with an optional name and no command; an agent can also place an existing window. The same controls are available through `hive dt tab`, `panel`, `split`, and `layout`.
- **Drive search has its own palette tab.** Use ⌘P or type `#` to search documents, rather than finding them among the main command palette's rows.
- **Session line counts include uncommitted work**, comparing the working tree with the merge base of the default branch.
- **Hive no longer runs `spawn` and `batch_spawn` rules.** A session always starts from the `windows` of its rule, or the default layout. A config that still sets these keys keeps loading, and hive logs a warning for each such rule. Move any commands you need into `windows`.
- **Task details open over the board.** The Tasks board opens details in a drawer without shifting the columns, and board keys wait until you close it.
- **Less clutter around terminals.** The Code status bar no longer repeats the agent's state or says Local; a working agent spins on its window row in the sidebar, and only server sessions name a host. The tab bar and bottom bar share the terminal's background, with a line between them.

## Fixed

- **Dev servers no longer show as running agents.** A terminal window started by an agent, such as a dev server, no longer shows a spinner and "claude is working" beside the window in Code.
- **Panel dividers no longer select text** when you drag them.
- **Drive comment and send hints show Ctrl** on Windows and Linux.
- **Title bar controls sit evenly** between its top and bottom edges.
