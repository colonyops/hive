## Added

- **Tabs and splits in Code.** Use `+` to add terminals, agents, Drive, Diff, or Tasks. Split right or down, nest splits, drag tabs between panels, and resize or turn splits. Drop markers show where tabs will land. The sidebar follows the tab order, and layouts survive restarts.
- **Diff review for local sessions.** Open Diff from `+` or the status bar's line counts. Compare branches, uncommitted work, staged or unstaged work, or individual commits. Search diffs, comment on lines or code, and send your review to the session's agent.
- **Sessions on servers in Code** (experimental). Servers under `servers:` in the hive config appear beside local sessions.
  - Create, open, edit, recycle, delete, or Start sessions, with terminals over ssh and the server's own launch rules.
  - The status bar shows the server, branch, uncommitted changes, and pull request. Open in editor, Show in Finder, and configured actions stay local-only.
  - Settings ▸ Servers shows connection checks. An offline server sends a notification and shows a red status dot with its ssh error on hover, without delaying local sessions.
- **Applets** (experimental). Build custom web pages with an agent; Applet Builder helps write the prompt.
  - Open applets from the palette or a shortcut, as Code or Chats tabs through `+`, or in the title bar with a dropdown. `applet.yaml` declares surfaces and commands; pages can add palette rows and run Hive commands. Shortcuts work inside applets, and agents can open or close their tabs.
  - Manage, disable, delete, or share `.hiveapplet` files in Settings ▸ Applets. **Applets have full access to your machine.** Import only those you trust; import shows files and commands before proceeding and never replaces an existing applet.
- **Images in Drive.** Select an image in the Drive tree to read it.
- **Task row actions.** Click the status icon to change status; hover or right-click for Mark done, Reopen, Copy ID, and Delete. Press `d` to complete or reopen the selected task.

## Changed

- **Separate text sizes.** Settings ▸ Appearance ▸ Text size sets Interface, Documents, Code, and Terminal as percentages. ⌘+, ⌘-, and ⌘0 resize the last area you clicked or focused; existing sizes carry over.
  - In `settings.yaml`, `terminal_font_size` and `canvas_font_size` become `terminal_scale` and `document_scale`. Their `HIVE_DESKTOP_APPEARANCE_*` overrides use the new names too.
- **Drive tabs replace the Chats pane.** Open Drive with `+` and split it beside a chat. Agent-opened documents arrive in background tabs with unread dots; `hive://chats` links with `canvas=` open those tabs too. The title bar's right button no longer toggles Drive in Code or Chats.
- **Agents control tabs and splits**, also through `hive dt tab`, `panel`, `split`, and `layout`.
  - MCP tools `open_tab`, `close_tab`, `move_tab`, `focus_tab`, `close_panel`, `resize_split`, `turn_split`, and `get_layout` replace `open_document`, `open_canvas`, and `close_canvas`.
  - Open Drive, Diff, Tasks, terminals, or applets behind, beside, or below the current tab. A new terminal is a shell in the Code checkout, with an optional name and no command; existing windows can move too.
- **Drive search has its own palette tab.** Use ⌘P or type `#`; documents no longer fill the main command list.
- **Session line counts include uncommitted work**, measured against the default branch's merge base.
- **Move `spawn` and `batch_spawn` commands into `windows`.** Hive no longer runs these rules; sessions use `windows` or the default layout. Old configs still load with warnings.
- **Task details open in a drawer** without shifting the board; board keys pause until it closes.
- **Quieter terminal bars.** Agent activity appears on sidebar window rows, not in the status bar; only server sessions name a host. Tab and bottom bars match the terminal background.

## Fixed

- **Agent-started dev servers and shells no longer show as working agents** in Code.
- **Dragging panel dividers no longer selects text.**
- **Drive comment and send hints show Ctrl** on Windows and Linux.
- **Title bar controls sit evenly** between its top and bottom edges.
