## Added

- **Compare images in the Changes view.** Preview versions side by side or with a swipe, with each version's dimensions and file size. The transparency grid picks light or dark to suit the image; you can switch it or show the image at actual size. SVG previews appear above their text diff.
- **Read text and code in Hive Drive.** Non-empty UTF-8 text files up to 4 MB open in the reader with line numbers and syntax highlighting, and update when the file changes on disk.
- **Fold sessions in the Terminal sidebar.** Each session has a chevron that hides or shows its windows. Collapse all and Expand all fold sessions too.

## Changed

- **Sending a review brings the agent's terminal forward.** After a successful send from the Changes view, you can read the agent's reply without finding its tab yourself.

## Fixed

- **GitHub search sources no longer fail together when one result requires SAML SSO authorization.** Hive skips results your token cannot read and keeps the rest, without stopping the other searches.
- **Editing a review comment puts the cursor in the comment.** Typed letters no longer trigger the Changes view's shortcuts.
