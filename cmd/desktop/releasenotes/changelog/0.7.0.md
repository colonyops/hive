## Added

- **A guided first run from setup to your first chat.** Choose the coding agent
  sessions should use and the folders that hold your repositories, and Hive
  writes that setup to the `hive` CLI config. A Default profile is ready from
  the start, connecting GitHub adds starter feeds, and the final step opens the
  built-in Hive workspace so your agent can help set up profiles and feeds.
  Existing `hive` CLI users keep their current config. Settings ▸ Hive CLI
  points to the file when you want to change it later.
- **Images in terminals.** Drag image files or paste screenshots into Code,
  Chats, and pop-up terminals to give your coding agent visual context without
  submitting the prompt.
- **Pull request status in the Inbox**, with CI, review state, and added and
  deleted line counts on GitHub search results and matching flow filters.
- **Agent workspace handoffs from Inbox.** The New Session dialog and
  `launch-session` actions can start a chat with a feed item's context, without
  a repository checkout.
- **Canvas reading controls** in Settings ▸ Chats let you set text size and line
  spacing across every canvas.
- **A ready-made Grafana dashboard for Hive's telemetry.** It shows the metrics,
  logs, traces, and profiles Hive exports, and ships in the repository's
  `grafana/` directory for pushing to your own Grafana stack with gcx. The
  Telemetry section of the settings guide links to it.

## Fixed

- **Linux installs appear in the application menu.** The terminal installer now adds a desktop entry and links to instructions when GTK or WebKitGTK runtime libraries are missing.
