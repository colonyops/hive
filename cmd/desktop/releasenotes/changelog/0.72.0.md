## Changed

- **Keep pages in title-bar tabs.** Inbox, Code, and Chats stay pinned. Use the + menu instead of the removed Views menu to open Drive, Tasks, Action runs, Settings, or an applet. Drag pages to reorder them; the tabs and their order stay across restarts. Tasks and Action runs open as pages instead of overlays. When a page is active, ⌘W closes it instead of hiding the window, including when focus is inside an applet. Applets opt into pages outside a session with the new `page` surface in `applet.yaml` or the Page switch in Settings ▸ Applets.
- **Canvases are gone from Hive Drive; agents write Markdown or HTML documents instead.** The eight `canvas_*` MCP tools, the `/mcp/canvas` address, the Hive Canvas MCP entry, and `hive://canvas/...` links are removed, along with the `canvas=` parameter on `hive://code` and `hive://chats` links. Point agent configs at `/mcp/drive` (Hive Drive), have agents use `document_put`, and link to documents with `hive://drive/<space>/<path>`. An existing `.canvas.json` file stays on disk and shows in Drive as a plain file.
- **File trees handle larger spaces and changes.** Drive and Changes load every row but draw only those near the visible area. The Changes view no longer stops at the first 1000 files. In Drive, the file tree scrolls on its own below Recent.
- **Recognize files and folders by their icons.** Drive, the Changes file tree, and diff headers use Material Icon Theme icons for the language, tool, or folder name.

## Fixed

- **The Changes view's Send button no longer looks frozen** while comments go to the agent. A spinner shows that the send is in progress.
- **HTML documents in Drive no longer show a wide white scrollbar track** down the right side on macOS when a mouse is connected. The page still scrolls with a trackpad, mouse wheel, or keyboard.
- **Update notes in Settings ▸ About render as Markdown** instead of showing raw formatting syntax.
- **Long addresses no longer crush the MCP settings layout.** Settings ▸ MCP wraps server addresses and setup commands so you can read them in full.
