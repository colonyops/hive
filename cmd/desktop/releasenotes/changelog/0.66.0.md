## Added

- **Terminal scrollbars** can be enabled in Settings ▸ Terminal for single-pane and zoomed Code terminals. Split layouts keep scrollbars hidden.

## Changed

- **Generated clone URLs follow your Hive CLI config.** `{{ .ItemRemote }}`, the New Session draft, and the seeded review actions use `git.clone_protocol` and `rules[].clone_protocol`, so issues and pull requests clone over SSH when you select it.
- **Document review now stays on the Drive page.** The Drive pane beside a chat or Code session no longer shows comments, so open the document on the Drive page to review it.

## Fixed

- **Equivalent Git remotes share one repository group.** Coding sessions with `git://`, HTTPS, or SSH remotes for the same repository appear together. Hover over a session to see its original remote.
- **HTML documents render and link correctly in Drive.** They fill the reader instead of opening as a blank page. A `#section` link scrolls within the document instead of loading Hive there, and a relative link does nothing.
- **Saving Settings ▸ Hive CLI preserves blank lines** in your Hive config.
- **Drive comments stay in place** when you open a different document.
- **New sessions keep starting after old sessions are recycled or pruned** instead of failing at "Spawning terminal..." with "The current working directory was deleted."
- **Terminals that showed images restore their width** when Hive Desktop closes during a redraw instead of remaining one column wide.
