## Added

- **More control in Chats.** Filter workspace and chat names, reload the list,
  start a new chat, or open the menu for workspace controls. Press `/` or ⌘F
  on macOS, or Ctrl+F on Windows and Linux, to focus the filter. A chat that is
  away from its live tail shows a Scroll to bottom button, and a stopped chat
  has a play button to start its agent.
- **A Code sidebar shortcut.** Press ⌘B on macOS or Ctrl+B on Windows and Linux
  to show or hide the left sidebar, even from a focused terminal. Change it in
  Settings ▸ Keyboard or use Toggle Code sidebar in the command palette.

## Changed

- **Session context shows by default.** The attached session's directory,
  branch, and pull request appear above the terminal. Existing settings are
  updated once on the next launch. Turn it off in Settings ▸ Terminal.
- **Workspace rows fold on a click.** Click a workspace to open or close its
  chats, as you would with a repository in the Code view.
- **Hive Desktop and Hive Canvas MCPs are stable.** Both first-party MCP
  servers no longer carry Beta or Experimental labels in the workspace editor.

## Fixed

- **Workspace edits are protected.** The workspace editor asks before Escape,
  the backdrop, Cancel, or the close button discards changes you have not saved.
