## Added

- **Action runs**, a log viewer for item and flow actions. It lists recent runs and shows each one's command line, interleaved stdout and stderr, and exit status, live while it runs. Open it from the title bar's Views menu, with `g` then `l`, or from **View log** on an item's action. The newest 100 runs keep their full logs; set `retention.action_runs` in `settings.yaml` to keep more or fewer. Agents can read the same runs over MCP with `list_action_runs` and `get_action_run`.
- **Shortcuts work from inside a terminal** when they start with ⌘ (Ctrl+Shift on Linux), including ones you add yourself and sequences such as ⌘G then I. Back (⌘[), Forward (⌘]), Settings (⌘,), Focus terminal (⌘→), and Report a problem (⌘⇧B) now stay with the app instead of reaching the terminal. Settings ▸ Keyboard marks the shortcuts that work there, and Terminal find is now a regular ⌘F shortcut you can change.

## Changed

- **Chat ids are UUIDs** in the local HTTP API and the MCP tools: a chat's `id`, a canvas's `session`, and a schedule run's `sessionId` are strings now, not numbers. A script that reads or sends a chat id has to treat it as a string. A chat that was running before the update keeps working under its old number.
- **The title bar's Views menu opens Action runs, Tasks, Canvases, and Settings.** Settings are available from every mode instead of the Inbox's profile rail. Activity now keeps the newest 1,000 events instead of 5,000.
- **Hive Desktop and the CLI now share the default `hive.log`**, with `service_name` identifying which program wrote each line. Settings shows the effective Hive data directory and shared log path.
- **The command palette matches multi-word queries across a row**, so "settings keyboard" or "Settings > Keyboard" finds the Keyboard settings page.

## Fixed

- **Large session prompts now launch reliably.** The New Session form warns when Hive will pass the prompt through a temporary file instead of a process argument.
- **Long-running item actions no longer block later manual or automatic actions.**
- **Scheduled Chats no longer confuse a new chat with a deleted run's chat**, which could make run history show the wrong live conversation.
- **Hive Desktop uses less CPU and memory** while the Code area shows session status and while flows poll their sources.
- **The New Session dialog keeps what you typed when you click outside it.** Use Cancel, the close button, or Escape to close it.
- **Linux app shortcuts no longer also reach the shell as control characters** when you press them in the pop-up terminal or a chat.
