## Added

- **Start and pin workspace chats from applets or agents** (experimental). Start a chat with an opening prompt and pin or unpin it in the Code sidebar. Applets use `hive.startChat`, `hive.pinChat`, and `hive.unpinChat`; agents use the new `hive-chats` MCP server. Pins follow the chat across windows.
- **Reply to agent reviews in the Diff view.** Add, edit, or delete replies beneath an agent's comment to give the session's agent context. The thread goes out with the comment when you send. Press `r` to reply during the review walkthrough.
- **Open session tabs from the command palette or a shortcut.** The palette offers "Open Drive tab", "Open Diff tab", and "Open Tasks tab" where the session supports them. Bind your own keys in Settings ▸ Keyboard with `session.open-drive`, `session.open-diff`, and `session.open-tasks`; these commands have no default shortcuts.

## Fixed

- **Linux startup** no longer fails with a D-Bus single-instance error for some data directories.
