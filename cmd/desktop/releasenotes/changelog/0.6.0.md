## Added

- **Multi-item sessions.** Select several inbox items to create one editable
  session with their combined context. The session appears in every selected
  item's detail pane.
- **Continuous Grafana Cloud profiles.** Set `telemetry.profiles` in
  `settings.yaml` to send CPU and heap profiles without a collector.

## Changed

- **Feed options in one menu.** Sorting, mark-all-read, and refresh controls now
  sit together in the feed header. Refresh progress remains visible while
  sources update.

## Fixed

- **The sidebar shortcut works in every app area.** Command-B on macOS or
  Control-B on Windows and Linux now shows or hides the sidebar in Inbox, Code,
  and Chats.
- **Restarted Code sessions use your default agent.** Pressing + on a stopped
  session now honors `HIVE_DEFAULT_AGENT` instead of falling back to
  `agents.default`.
- **Command palette chat rows focus the chat pane**, so you can type immediately
  after opening a chat.
- **Completed flow nodes show the correct age** instead of reporting elapsed
  times of hundreds of thousands of hours.
