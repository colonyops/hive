## Added

- **Saved views in the Code sidebar.** Filter sessions by tag, repository, status, or age, then save and switch between named views. Use Manage views to rename, reorder, or delete them. The built-in Running view replaces the "Only running sessions" toggle.
- **Code sessions through the hive daemon** (experimental). With `experimental.daemon: true` in the hive config, the Code view creates, renames, and deletes sessions and reads agent status through the same daemon the hive CLI and TUI use, so both apps show the same status. `daemon.hive_path` in `settings.yaml` names the `hive` binary that runs it when `hive` is not on your login shell's `PATH`.

## Changed

- **Faster terminal output and resizing.** A terminal printing a wall of text uses about a third of the CPU and draws about 60% more output per second. A single resize, such as toggling the sidebar, redraws in about 33 ms instead of about 116 ms.
- **Smooth mouse-wheel scrolling in terminals.** A physical mouse wheel now scrolls smoothly; trackpads still track one to one.

## Fixed

- **Code and Chats open faster**, including the first time after launch. Moving between them no longer stalls, animates the session list into place, or makes the page jump while it loads.
- **Terminal tabs and sessions show the current screen** when you switch to them, instead of briefly flashing old contents from before a hidden program redrew.
- **Reused clones no longer inherit the previous session's identity.** A new session gets its own inbox and group without inheriting the old session's tasks, and an inbox item linked to the old session no longer shows the new session under its name.
