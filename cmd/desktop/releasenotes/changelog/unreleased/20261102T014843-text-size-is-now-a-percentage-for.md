**Text size is now a percentage for each area.** Settings ▸ Appearance ▸ Text size sets Interface, Documents, Code, and Terminal separately, and the interface can scale for the first time. ⌘+, ⌘-, and ⌘0 change the area you last clicked. Your terminal and document sizes carry over. The `terminal_font_size` and `canvas_font_size` settings become `terminal_scale` and `document_scale`, and their `HIVE_DESKTOP_APPEARANCE_*` overrides are renamed to match.
