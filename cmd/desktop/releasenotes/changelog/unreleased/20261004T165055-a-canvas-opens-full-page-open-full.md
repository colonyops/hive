**Canvases open full page.** A canvas now opens over the current view with the workspace's canvases in a sidebar, so a long report or a set of linked canvases reads like a small wiki. Open it with **Open full page** in the canvas pane, by picking a canvas in the command palette, or with ⌘⇧P or `g v`. Escape or the shortcut again returns to where you were. A Markdown link that names another canvas in the workspace opens that canvas in place, in the pane as well. Copy as Markdown, save to a file, and the canvas filter work as they do in the pane.
