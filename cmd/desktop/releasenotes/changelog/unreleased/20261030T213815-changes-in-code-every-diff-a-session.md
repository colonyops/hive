**Changes** in Code: every diff a session's agent made, in one scroll beside its file list, and keyboard driven. Compare against any branch, or show uncommitted work, staged work, unstaged work, or one commit at a time. Search the diffs, comment on selected lines or code, and send the comments to the session's agent. It works for a session on a server. Open it with ⌘⌥G or from the status bar.
