**Drive is a tab in Chats too.** The Drive pane beside a chat is gone. An open chat shows as a tab, and the `+` on its tab row opens Drive beside it; split the panel to read a document next to the conversation. A document an agent opens arrives as a Drive tab behind the one you are reading, with a dot until you look at it, and a `hive://chats` link with `canvas=` opens that tab. The title bar's right button no longer toggles Drive in Code or Chats. For agents, the Hive Drive MCP tools `open_document`, `open_canvas` and `close_canvas` are replaced by layout tools: `open_tab`, `close_tab`, `move_tab`, `focus_tab`, `close_panel`, `resize_split`, `turn_split`, and `get_layout`. An agent can do with the tabs and panels what you can, and read the layout first. `open_tab` names a view (`drive`, `diff`, `tasks`, `terminal`) and places it behind the current tab, beside it, or below it; a `terminal` is a new tmux window in the Code session's checkout, with an optional name and a command to run, or an existing window the agent names. The same controls are in the hive CLI as `hive dt tab`, `hive dt panel`, `hive dt split`, and `hive dt layout`.
