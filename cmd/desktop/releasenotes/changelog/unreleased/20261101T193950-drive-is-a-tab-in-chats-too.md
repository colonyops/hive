**Drive is a tab in Chats too.** The Drive pane beside a chat is gone. An open chat shows as a tab, and the `+` on its tab row opens Drive beside it; split the panel to read a document next to the conversation. A document an agent opens arrives as a Drive tab behind the one you are reading, with a dot until you look at it, and a `hive://chats` link with `canvas=` opens that tab. The title bar's right button no longer toggles Drive in Code or Chats. For agents, the Hive Drive MCP tools `open_document`, `open_canvas` and `close_canvas` are replaced by `open_tab` and `close_tab`, which name a view (`drive`, `diff`, `tasks`) and can open it behind the current tab or beside it in a split.
