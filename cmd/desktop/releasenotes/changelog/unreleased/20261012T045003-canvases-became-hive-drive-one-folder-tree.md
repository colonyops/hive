**Canvases became Hive Drive**: one folder tree per repository, workspace, and the shared space, with markdown and html documents beside canvases, search across every space, and live refresh when a file changes on disk. Open it with Toggle Drive (`⌘⇧P`) or a `hive://drive/<space>/<path>` link, and set its reading controls in Settings ▸ Drive. On first launch a chat's canvases move out of its workspace folder into the drive, and global canvases move to the shared space; deleting a workspace now leaves its documents in the drive. An earlier version of Hive does not find canvases once they have moved.
