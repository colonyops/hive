**Remote Code (experimental)** lists remote repositories, sessions, and agent or terminal windows alongside local ones. New session offers repositories from both machines and uses the selected machine’s agent profiles. Remote terminals support input and resize over SSH, with the same Git and pull-request status bar as local sessions. Reconnect restores the server connection across sessions without losing your selection.

Configure named connections and their colors in Settings ▸ Remote.
