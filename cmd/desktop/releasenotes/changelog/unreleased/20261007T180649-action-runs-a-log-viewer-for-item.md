**Action runs**, a log viewer for item and flow actions. It lists recent runs and shows each one's command line, interleaved stdout and stderr, and exit status, live while it runs. Open it from the new views menu in the title bar, with `g` then `l`, or from **View log** on an item's action. Agents can read the same runs over MCP with `list_action_runs` and `get_action_run`.
