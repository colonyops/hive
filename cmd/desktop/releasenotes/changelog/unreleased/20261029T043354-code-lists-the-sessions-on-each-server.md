**Sessions on servers in Code** (experimental). Code lists the sessions of each server under `servers:` in the hive config next to your local sessions, with the server's state. You can create, open, edit, recycle, and delete a session on a server, and its terminal runs over ssh. **Settings > Servers** shows how each server answered its last check. An offline server shows its ssh error and does not slow down the rest of the list.
