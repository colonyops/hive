**An orchestrator workspace drives hive sessions across repositories.** The new **Hive Orchestrator** MCP server lets an agent start a hive session in a repository with a prompt, watch it, type into it, answer its permission prompts, and wait for it on the message bus. Hive adds an **Orchestrator** workspace with it enabled. Only a workspace that lists the server, or a client holding an access token from **Settings ▸ Orchestrator**, can use it.
