**Canvases in Code.** An agent in a Code session can now publish canvases, and the session gets the same canvas pane a chat has, opened from the title bar's right-panel button. Add the server to your agent's own MCP configuration to turn it on: the new Settings ▸ MCP servers page shows each server's address and the setup for Claude Code, Codex, and other agents, and Hive never edits that configuration for you. A session's canvases belong to its repository and are kept in the repository's hive context directory, so every session of the repository shares them and they outlive the session. The full-page view and the command palette list them beside your workspaces' canvases.
