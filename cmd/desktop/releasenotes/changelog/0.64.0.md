## Added

- **`hive://` links** (experimental) open a Code session, chat, inbox item, Drive document or space, or canvas. Hive raises its window and goes there, and starts first if it is not running.
- **Easier-to-use rendered code blocks.** Fenced code in the feed, Drive, and canvases has syntax highlighting in a theme that matches the app. Code blocks in the feed, tasks, Drive, and release notes show a copy button on hover.
- **Interface errors appear in Diagnostics.** Errors and warnings from the app's interface, including uncaught exceptions, are written to `hive.log`, so they also appear in problem reports.
- **Hive Drive telemetry** reports document read and write duration and failures, space scans, file watching, and agent tool calls. The Grafana dashboard includes a Drive tab for these signals.

## Changed

- **Canvases became Hive Drive**: one folder tree per repository, workspace, and shared space, with Markdown and HTML documents beside canvases, search across every space, and live refresh when files change on disk. You can create folders; rename, move, and delete documents and empty folders; or drag a document onto a folder without a running agent. Agents can write Markdown and HTML documents through the `hive-drive` MCP server and file canvases under folder paths. HTML documents fill the reader in a sandboxed frame, where scripts run but cannot call Hive or send requests to localhost; existing `hive-canvas` configurations still work. Open Drive with Toggle Drive (`⌘⇧P`) or a `hive://drive/<space>/<path>` link, and set its reading controls in Settings ▸ Drive. On first launch, Hive moves chat canvases out of workspace folders and global canvases into the shared space; deleting a workspace now leaves its documents in Drive. Earlier Hive versions cannot find canvases after they move.
- **The + in Chats opens the New session dialog**, with Chats selected and the focused workspace filled in. A chat started there can take an opening prompt.
- **`hive.log` rotates at 10 MB**, and Hive Desktop keeps the three most recent files instead of letting the log grow without limit.

## Fixed

- **Terminal panes no longer print command names before their output** when a shell sets the window name, as oh-my-zsh does by default.
