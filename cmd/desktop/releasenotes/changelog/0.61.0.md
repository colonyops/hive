## Added

- **Global canvases** give agents outside a chat or Code session a shared place to publish. Pass `global` as the session, then open the canvases under **Global** in the full-page canvas view or from the command palette.
- **Mermaid diagrams in canvases.** Agents can put fenced Mermaid diagrams in Markdown beside a chat or Code session. Diagrams follow the current theme, support pan and zoom, and preserve their source when copied or saved.
- **Stat cards for canvases** let agents publish a row of up to six figure tiles. Each tile can include a unit, a secondary line, and a tone that flags a number that needs attention.
- **Session age badges** mark older sessions in the Code sidebar. They appear after five days by default; change the threshold or disable them in Settings ▸ Terminal. Reused recycled clones start again at day zero.
- **Workspace skills written by agents persist.** A skill created in a chat workspace's `.claude/skills/` or `.agents/skills/` survives when the workspace opens. Hive replaces or removes only the skills its packages install.

## Changed

- **Canvas display settings have their own page.** Settings ▸ Canvas controls text size and line spacing in Chats and Code, plus the full-page view's **Text width**. The full-page view now opens at Narrow; choose Wide for the previous layout or Full to use all available space.
- **Canvas blocks have a new look** that follows the active theme: stat cards lead with a mono label and mark their tone with a dot, badges are compact tags, callouts use a thin rule, tables drop their cell borders, and link blocks are cards.

## Fixed

- **Sessions with similar names open their own terminals.** The Code view no longer opens a longer-named session when the selected session is stopped.
