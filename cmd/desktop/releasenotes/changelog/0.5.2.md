## Changed

- **Report a problem opens a GitHub issue.** It fills in your version and
  platform without uploading or attaching diagnostic data.
- **Saving a diagnostic bundle is now a separate command.** Logs, settings,
  flows, and actions are optional. Secrets are stripped, but bundles still name
  your home directory, repositories, and branches, so send them privately when
  a maintainer asks for one.

## Fixed

- **Review request authors** now appear in the feed list and right sidebar for GitHub notifications.
