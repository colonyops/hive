# Hive Canvas

`hive-canvas` is the `hive-drive` server at its older address,
`http://127.0.0.1:<port>/mcp/canvas`. It is kept for agent configurations
that already point there and serves exactly the same tools: the canvas tools
and the document tools. See `hive-drive` for what they do.

A new workspace lists `hive-drive` instead, which reaches the same server at
`/mcp/drive`. Listing both connects the agent to the same server twice.
