## Added

- **`hive mcp serve` connects agents to Hive Desktop over stdio**, so MCP configuration needs no port: `claude mcp add hive-drive -- hive mcp serve --toolset drive,layout`. It finds the running app on every call, fills the `caller` argument itself, and answers `unavailable` while the app is closed.

## Changed

- **`hive dt` has a command for every Hive Desktop tool**, including `hive dt document put`, `hive dt inbox list --profile-id <id>`, and `hive dt schedule list`. Pass fields as flags or the whole input as JSON through `--input`. Update existing commands: `hive dt layout` becomes `hive dt layout get`, `hive dt tab close terminal` takes `--window`, `--session` becomes `--caller`, and `--url` becomes `--desktop-url`.
- **Use `--json` for JSON Lines output and check exit codes by error kind.** JSON output is compact, with one value per line on stdout; errors go to stderr.
  - Replace `hive doctor --format json` with `hive doctor --json`, and `--jsonl` with `--json` on `hive x assess watch` and `replay`. Replace `hive x pick --print --format json` with `hive x pick --print --json`; `--format` still accepts `id`, `name`, and `path`, and `--json` requires `--print`.
  - `hive config`, `hive batch`, `hive hc prune`, `hive hc context --json`, and `hive detect` print one JSON line instead of indented JSON. `hive doctor` prints its text report to stdout.
  - In JSON mode, errors print one JSON line with `kind` and `message` on stderr. `hive session info --json` no longer prints an error on stdout.
  - Exit codes are 2 for `invalid`, 3 for `not_found`, 4 for `conflict`, 5 for `unavailable`, 6 for `unauthenticated`, and 1 for other errors, in text and JSON modes. An unknown flag exits 2. `hive drive push`, `pull`, and `share` exit 6 when no Drive Server login exists or the server answers 401, with a message explaining how to log in.
- **Use long flags where short forms had conflicting meanings.** These short forms no longer select their former flags: `-a` (`--all`), `-f` (`--force`, `--format`), `-n` (`--new`), `-p` (`--prefix`, `--print`), `-r` (`--repo`), `-s` (`--sender`, `--shared`, `--status`), `-t` (`--tags`, `--title`, `--tool`, `--type`), and `-w` (`--workspace`). Each letter keeps one meaning across commands; `-t` remains `--topic`.
- **`hive msg inbox` takes `--caller` and `hive hc list` takes `--session-id`**, replacing their `--session` flags. `--caller` accepts a session id or name and defaults to `HIVE_AGENT_SESSION`, as in `hive dt`. `--session-id` accepts a bare id or `local:<id>`; an id qualified with another server is an error rather than a warning, because Honeycomb items are local.
- **`hive drive push`, `pull`, and `share` take `--drive-server` instead of `--server`.** `--server` now consistently names a server under `servers:` in the hive config. `HIVE_DRIVE_SERVER` still sets the Drive Server default.
- **Use `hive hc context`, not `hive hc ctx`.** The `ctx` alias remains only on `hive ctx`, the old name of `hive drive`.

## Fixed

- **`hive batch` and `hive session info` no longer report success on failure.** Unreadable or invalid batch input and a session-info request outside a hive session now return a nonzero exit status.
