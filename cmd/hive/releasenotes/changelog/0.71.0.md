## Added

- **Start and pin Hive Desktop chats from the CLI or MCP** (experimental). Use `hive dt chat create` to start a workspace chat with an opening prompt, `hive dt chat list` to list chats, and `hive dt chat-pin put` or `delete` to pin or unpin them in Code. `hive mcp serve` offers the same tools in the `chats` toolset. The CLI reads the running desktop's token automatically.

## Fixed

- **Desktop tools work through `hive mcp serve` without unexpected `caller` errors.** Tools such as `applet_list`, `workspace_list`, and `session_list` no longer fail because they receive an argument they do not accept.
