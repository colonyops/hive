## Added

- **Assign tasks to a named session or chat.** `hive hc create` and `hive hc update` take `--assign-session <session-id>`, so you can hand out work from outside a session. A tree passed with `--input` accepts `assignSession` on each child; the `task_create` and `task_update` MCP tools take the same input.
- **Tag tasks and epics.** Set tags with `hive hc create --tags`, change them with `hive hc update --add-tag`, `--remove-tag`, or `--clear-tags`, and find items with `hive hc list --tags`. A match must have every requested tag. Bulk creates accept a `tags` list per item, and the `task_*` MCP tools accept the same fields. Tags follow the same rules as session tags.
- **Read and answer shared-document comments.** `hive drive comments` lists threads on a pushed document; its `reply`, `resolve`, and `reopen` subcommands let you respond.
- **Review server sessions from Hive Desktop.** With the same hive version on the server, Desktop can send Changes reviews to its agents and show or dismiss the diff comments those agents write.

## Changed

- **Update scripts for the new command forms.** `hive hc`, `hive msg`, and `hive todo` print JSON Lines when stdout is not a terminal and accept `--caller` and `--input` (inline JSON, `@file`, or `-` for stdin). `--json` and the short flags are gone. The old verbs `show`, `ls`, `prune`, `pub`, and `add` remain aliases, but their arguments follow the new forms:
  - **Tasks:** use `hive hc get` for `hc show`, `hc comment create` for `hc comment`, `hc context get` for `hc context`, and `hc clear --statuses` for `hc prune`. Use `hc create --parent-id` instead of `--parent`, `--input -` for a JSON tree, and `hc list --status all` instead of `--all`.
  - **Messages:** use `hive msg create --topics <topic> --payload <text>` instead of `msg pub -t ... -m`. `msg list` reads messages; `msg topic list` lists topics. Create a topic with `msg topic new` and mark messages read with `msg read put`.
  - **Todos:** use `hive todo create` instead of `todo add`, without the old `-u` and `-s` flags.
  - **Desktop commands:** two-word resources now use nested groups, such as `hive dt chat pin put` instead of `hive dt chat-pin put`.
