## Added

- **New repositories in a workspace show up without a restart.** The TUI watches your workspace directories and lists a repository as soon as it appears. If the watcher stops, `WorkspaceRefresh` in the command palette rescans them, and you can bind it to a key.
- **`hive init` asks where to add the `hv` alias.** It suggests the rc file for your `$SHELL`, falling back to `~/.zshrc`, and lets you change the path if your shell config lives elsewhere.

## Changed

- **Session names have one set of rules.** A name is unique on its slug, so `Fix Bug` and `fix-bug` count as the same session, and a name is at most 60 characters. `hive batch` now checks names the same way as `hive new`. A source template whose name is taken gets the item id as a suffix instead of failing, and accented letters in a title fold to their base letter (`Café` to `cafe`).
- **Messages are capped per topic.** `hive msg pub` keeps the newest 100 messages in each topic and deletes older ones, the same limit Hive Desktop already applied to the shared database. Set `messaging.max_messages` to change the limit, or `0` to keep every message.
- **Pane capture recording is removed.** `tmux.capture_recording` in `config.yaml` no longer does anything, so drop the key. Recordings already under `recordings/tmux` in the hive data directory stay where they are; delete them when you no longer need them.
- **`hive ctx prune` keeps `canvases/`.** Hive Desktop stores a repository's canvases in its context directory, and prune no longer removes that directory however old it is.

## Fixed

- **A failed session create says why.** The error now includes the git command's output, the destination, and the clone strategy instead of only an exit status.
