## Added

- **`hive drive login`, `push`, `pull`, and `share`** connect Hive Drive to a drive server. `login` stores an API token for the server, `push` and `pull` copy documents in either direction, and `share` prints a public link to a document. `hive drive` also takes `--workspace` to target a Chats workspace's space by name.
- **Configurable clone protocols for generated remotes.** Set `git.clone_protocol` globally or `rules[].clone_protocol` per repository to choose HTTPS or SSH when Hive builds clone URLs from issues and pull requests.

## Fixed

- **Equivalent Git remotes act as one repository.** The sessions tree groups SSH, HTTPS, and `git://` remotes for the same repository on any host. Recycled clones, `max_recycled` limits, and worktree bare clones are shared across SSH and HTTPS spellings, while bare clones stay separate between hosts.
- **The TUI new-session form copies files from the selected checkout** instead of the directory where you started the TUI.
- **New sessions keep starting after old sessions are recycled or pruned** instead of failing with "The current working directory was deleted."
