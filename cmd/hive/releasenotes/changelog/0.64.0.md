## Added

- **`hive drive` (alias `hive ctx`)** lists a space's documents with their kinds; `--all` lists every space, `--json` prints one object per line, and `hive drive spaces` lists the spaces. `hive review` opens any Markdown document and groups the picker by its front matter `type:`, while `hive review --all` picks from every space.
- **`hive desktop`** (experimental) opens a `hive://` link in Hive Desktop with `hive desktop open` (alias `hive dt open`). `hive desktop --help` lists the link formats.

## Changed

- **`hive drive` changes some output you may script against.** `hive ctx ls` prints one `kind  path` line per entry instead of a tree, and it no longer lists dot entries or symlinks. In a review user command, `.Doc.Type` is the document's front matter `type:`, or its top folder name when it has none. The repository owners `shared` and `workspaces` are reserved, because their folders hold the shared and workspace spaces.
- **`hive.log` rotates at 10 MB**, and hive keeps the three most recent files instead of letting the log grow without limit.

## Fixed

- **The open-all-context-directories command** opens the directory that `context.base_dir` points at instead of the default directory under the data directory.
