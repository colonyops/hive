**Editable session tags.** `hive session update` takes `--add-tag`, `--remove-tag`, and `--clear-tags`, and the TUI has one Edit Session modal for the name and the tags: `R` opens it on the name, `ctrl+t` on the tags. The session tree shows tags at the end of each row and in the preview header, and `/` matches them.
