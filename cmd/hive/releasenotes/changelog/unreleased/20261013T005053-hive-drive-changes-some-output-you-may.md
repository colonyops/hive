**`hive drive` changes some output you may script against.** `hive ctx ls` prints one `kind  path` line per entry instead of a tree, and it no longer lists dot entries or symlinks. In a review user command, `.Doc.Type` is the document's front matter `type:`, or its top folder name when it has none. The repository owners `shared` and `workspaces` are reserved, because their folders hold the shared and workspace spaces.
