**`hive dt tab`, `panel`, `split`, and `layout`** drive the tabs and panels beside a chat or Code session in Hive Desktop: open Drive, Diff, Tasks, or a terminal with a command, move and focus tabs, close panels, resize and turn splits, and print the layout as JSON. They call the app's MCP tools, found through the endpoint file the desktop writes, or `--url`.
