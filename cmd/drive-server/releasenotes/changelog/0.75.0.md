## Added

- **Discuss shared documents and see who is reading.** Comment threads and live presence work through existing share links. Any account that can sign in to the server can comment; anonymous readers can read threads and appear in presence but cannot write. Threads follow their text when a document is pushed again and show as outdated when the text is gone. Behind a proxy, set `trusted_proxies` so readers do not all share one per-IP stream cap.
- **Read file trees, call paths, and forge cards in shared docs.** Fenced `hive-tree`, `hive-calls`, and `hive-forge` blocks render inline as file trees, call paths, and PR and issue cards. `[[wikilinks]]` link documents in the same space.
